# 蓝色 STM32F103C8T6 + Stamp-S3Bat DIP 硬件连接方案

日期：2026-10-14。适用当前10号工程；野火11号工程的串口不同，不能套用此表。本方案为接线设计与检查清单，未连接、烧录或驱动实物。

## 当前控制链路与配置前提

安卓电机控制台 → BLE v3（16字节命令/20字节状态）→ Stamp-S3Bat DIP → 3.3V TTL UART v2（32字节/115200/8N1）→ STM32 TIM1/PB0 → 接口电路 → T60 → 57A1ED。

本版没有CAN传输、CAN报文ID或CAN异常恢复代码；SN65HVD230不进入这条链路。T60照片上的RS232是设置接口，不是当前电机运动命令接口，不能接MCU TTL UART。

**当前ESP UART/ADC、STM连续运动仍默认关闭，但STM复位后的一次22.5°指令动作仍保留。** 即使手机未连接，STM也会在约1秒后发出示例100个脉冲。先测MCU波形时不要接驱动器PUL；连电机前必须理解这一行为。启用ESP UART后，它的启动STOP会取消尚在等待或运行的本地动作。

## 1. 已核实的硬件与缺口

| 项目 | 材料确认 | 仍待确认 |
|---|---|---|
| ESP核心板 | S015-DIP，ESP32-S3-PICO-1-N8R8，8MB Flash/8MB PSRAM；DIP引出G1–G11 | 实际安装朝向、其他外设占用、供电接法 |
| STM32 | 工程目标STM32F103C8T6，HSE按8MHz | 蓝板具体原理图、晶振实物频率、供电输入和板载负载 |
| T60 | 所给照片有PUL/DIR/ENA/ALM、差分编码器、A/B绕组、RS232；铭牌DC18–68V | 照片对应实物版本、输入电路/电流、有效边沿、DIR与ENA时序 |
| T60参考手册 | V2.0版写DC24–50V、PUL/DIR 3.3–24V兼容、ENA默认光耦导通释放电机 | 不能将V2.0所有参数认定为照片中的旧版参数 |
| 电机 | 所给57A1ED照片铭牌写1.8°/4.0A，并列出绕组和编码器线色 | 扭矩、绕组电阻/电感、编码器分辨率、实际延长线线序 |

1.8°是电机机械整步角；4.0A是铭牌电流，不能直接当作动力电源输入电流。参考手册的4000编码器/控制精度描述、驱动器每圈指令脉冲数和1.8°不能相互替代。57AM13ED资料不是57A1ED型号证明。

本地依据：02目录的官方说明PDF第3、5–7页及原理图；06目录原图与V2.0手册第9–18、20页；07目录原图；03目录模块原理图第1页与TI数据手册。原图不是当前接线测量证据。

## 2. 低压供电与UART

优先采用独立、稳压的5V逻辑电源：Stamp接明确的5VIN/GND或USB-C；STM接蓝板实际厂家允许的5V输入，或按板说明用3.3V供电。STM32芯片及IO为3.3V，不能直接吃5V。

Stamp也支持单节3.7V锂电池输入；不是24V输入。只有在确认电源接口方向、充电芯片版本和电池规格后才连接电池。不要把T60动力电源接到Stamp/STM，或把两块板的稳压输出并在一起。

| 端点A | 端点B | 状态/依据 |
|---|---|---|
| Stamp G4，建议UART1 TX | STM PA3 / USART2 RX | G4在DIP排针引出，软件待配置 |
| Stamp G5，建议UART1 RX | STM PA2 / USART2 TX | G5在DIP排针引出，软件待配置 |
| Stamp GND | STM GND / 逻辑电源GND | 普通非隔离TTL需要公共信号参考 |
| STM PA9/PA10 | 可选电脑USB-TTL RX/TX | USART1预留；确认转换器是3.3V TTL |
| STM PB10/PB11 | 当前不接 | USART3只初始化预留 |

ESP `menuconfig → Robot UART to STM32`：启用UART、port=1、TX=4、RX=5、115200。UART1与控制台UART0分开。G4/G5是根据此DIP板资料提出的分配，不是已完成的实际接线。避免G19/G20 USB、G43/G44控制台、G47/G48板载M5PM1 I2C以及启动相关G0/G3/G45/G46。不会把GPIO编号等同于排针序号。

本板电池状态原生由M5PM1监测（G47 SCL/G48 SDA、地址0x6E）；当前工程没有M5PM1驱动。现有可选ESP ADC是外部电池分压方案，不会自动读板载电池。ADC默认关闭、未知电压显示未接入；若外接分压必须按实际电压和电阻重新计算，不能将24V接到当前100k/33k示例分压（输出约5.95V）。

## 3. MCU到T60：条件式接口方案

未确认实物输入电路前，不直接连PA8/PB0到驱动器端子。参考手册写3.3–24V兼容，并在故障排查建议增强到7–16mA信号；这不是本机在3.3V下输入电流的确认。ST数据手册也不能将GPIO的绝对电流上限当作保证电平的工作条件。

候选采用共阳极、5V信号电源、两路NPN下拉接口（每路一只2N3904或同类已核实规格的NPN）：

```text
PA8 ── 1kΩ ── Q1基极              +5V信号 ── PUL+
               │                  Q1集电极 ── PUL-
              10kΩ                Q1发射极 ── 逻辑GND
               │
           逻辑GND

PB0 ── 1kΩ ── Q2基极              +5V信号 ── DIR+
               │                  Q2集电极 ── DIR-
              10kΩ                Q2发射极 ── 逻辑GND
               │
           逻辑GND
```

基极10k下拉使MCU复位/高阻期间晶体管保持关断；实际电阻、晶体管脚序与驱动电流需按实物核实。驱动器若自带限流，不重复猜外部限流值；若需要串联限流，应先查内部电路并按允许电流计算、实测。5V信号电源不是T60的V+动力电源。

MCU高 → 晶体管导通 → PUL-/DIR-对地电压低；**负端单端波形反相，而PUL+−PUL-的差分有效电压随MCU高而高**。要按驱动器识别的差分/光耦有效边沿核对计数，不能只看PUL-对地波形宣称方向/边沿正确。当前PWM2高/低均为软件测试值，本机最小输入脉宽仍无证据，不能断言已满足厂家时序。

此方案逻辑侧GND与ESP/STM/5V信号电源相连。若实物PUL/DIR是光耦隔离输入，信号环路无需仅为UART而把T60动力V-接到MCU；是否接动力地、屏蔽地按实物隔离电路和接地方案确认。若另加信号隔离器，要保持隔离电源/地的边界。

ENA：目前PB1仅作候选、代码没有驱动ENA。参考V2.0默认ENA光耦关闭时驱动、导通时释放且忽略脉冲，极性可设置；旧版实物须核实。暂不将ENA接到MCU。**软件STOP只停止PUL，不断动力、不必释放锁轴，不是硬件急停。** ALM输出也未接MCU，不会把驱动器报警回传伪装成已实现功能。

## 4. 动力、绕组与编码器

动力电源独立接T60 V+/V-；NC悬空。24V属于所给照片和V2.0手册范围的交集，可作初步电源方案，但最终仍须匹配实物版本、允许电流与负载。不能凭照片18–68V便选68V，也不能把4A绕组电流等同于电源输入需求。

按所给57A1ED铭牌，原电机线的候选对应如下；延长线/改装线应断电核对，不按照片裁切处猜当前接线。

| 电机原线 | T60端子 | 含义 |
|---|---|---|
| 红 / 蓝（动力线束） | A+ / A- | A相绕组 |
| 绿 / 黑（动力线束） | B+ / B- | B相绕组 |
| 绿 / 黄（编码器线束） | EB+ / EB- | 编码器B相差分 |
| 棕 / 白（编码器线束） | EA+ / EA- | 编码器A相差分 |
| 红 / 蓝（编码器线束） | VCC / GND | 编码器电源；参考手册为驱动器5V输出，实物待核实 |

两个线束都有红/蓝线，不能混接。编码器接T60，不接STM UART、CAN或MCU 3.3V电源。没有把另一型号57AM13ED的编码器分辨率或扭矩套到本机。

## 5. 拨码、角度与速度

候选N=1600脉冲/圈对应照片/参考表：SW1 ON、SW2 OFF、SW3 ON、SW4 ON；实际拨码与软件参数未读回。SW7应为PUL/DIR单脉冲模式（照片/参考手册OFF）；闭环SW8 OFF、SW5方向和SW6滤波需核实，参考手册要求断电后改变并重新上电生效。

`目标脉冲 = round(N×22.5/360)`，N=1600示例得到100脉冲；若N=200，13脉冲对应23.4°、误差+0.9°。不能用电机1.8°推定N=200，也不能用编码器分辨率推定N。

TIM1时钟72MHz、PSC=71 → 计数1MHz；ARR=9999、CCR=5000的PWM2 → 100Hz，高/低各5ms。连续接口示例1–100%映射100–1000Hz，0%=STOP；N=1600假设下对应3.75–37.5指令rpm，不是实测转速或额定范围。

换向软件先停止PUL，保持示例2ms，切DIR，再建立示例10ms后输出。往复两段时长包含该逻辑等待，不能当作等长脉冲列；没有机械减速到零/加速斜坡。T60 V2.0若打开滤波，手册示例6.4ms（可设到25.6ms内）还会引入延迟；旧版与本机设置均未知。电机带载往复前需确认相应时序和机械条件。

## 6. CAN模块仅预留

SN65HVD230是3.0–3.6V CAN物理层收发器，不是控制器。ESP32-S3有TWAI，STM32F103C8T6有bxCAN；这版代码均未配置其通信。

若将来另行开发CAN，可候选预留Stamp G6=TWAI TX、G7=TWAI RX，以及STM PA12=CAN TX、PA11=CAN RX；后者与STM USB复用冲突。每个节点各需收发器，TX接模块CAN_TX/D，RX接CAN_RX/R，GND及3.3V正确连接，CANH/H与CANL/L双绞连接。不要把UART TX/RX接到CANH/L。

所给模块原理图第1页有固定R2=120Ω跨CANH/CANL、Rs经10k到地。总线仅两端各120Ω，不能每个中间节点保留终端；两端并联断电测量约60Ω。须核对实际模块是否同版、R2是否可去除。Classic CAN单帧载荷最多8字节，不能把32字节UART帧当一帧CAN直接发送；波特率、ID、分帧、确认及bus-off恢复都尚未实现。因此当前最小接线方案不连接CAN。

## 7. 分阶段测试门槛

1. 不接驱动器，确认板供电、晶振及MCU复位后PA8/PB0波形；确认本地一次动作与STOP取消行为。
2. 仅连ESP/STM的3.3V UART，启用已确认GPIO，验证32字节CRC、STOP、重连、拔线超时；此时STM连续模式仍关闭，运动返回NOT_READY。
3. 单独验证接口电路电压、光耦电流、有效边沿与复位状态。确认T60实物模式/版本、供电、ENA与编码器线序后才能接驱动器。
4. 确认N、方向和时序后启用连续能力，低速空载验证；最终再评估负载、换向、机械急停和报警输入。编译、协议模拟和APPLIED均不是实际电机转角证据。
